# 康寧大學就讀意願登錄系統

## 系統概述

這是一個完整的就讀意願登錄系統，允許學生和家長填寫就讀意願表單，管理員可以查看和管理這些申請。

## 功能特色

### 學生功能
- 📝 **就讀意願登錄**: 填寫詳細的個人資料和就讀意願
- 📋 **多項意願選擇**: 可選擇三個就讀意願，包含學制和科系
- 📞 **聯絡資訊**: 提供多種聯絡方式（電話、Email、Line、Facebook）
- 🏫 **國中資訊**: 填寫就讀或畢業國中資訊
- 📝 **備註功能**: 可添加額外說明或特殊需求

### 老師功能
- 🔍 **申請列表管理**: 查看所有就讀意願申請
- 📊 **篩選功能**: 依狀態、身分別、日期篩選申請
- ✅ **狀態管理**: 更新申請狀態（待聯絡、已聯絡、已入學）
- 📋 **詳細檢視**: 查看申請的完整資訊
- 📈 **統計資訊**: 查看各狀態的申請數量統計

## 系統架構

### 資料庫表結構
```sql
enrollment_applications (
    id,                    -- 申請編號
    username,              -- 用戶帳號
    name,                  -- 姓名
    identity,              -- 身分別 (學生/家長)
    gender,                -- 性別 (男/女)
    phone1,                -- 聯絡電話1 (必填)
    phone2,                -- 聯絡電話2
    email,                 -- 電子郵件
    intention1,            -- 就讀意願一
    system1,               -- 學制一
    department1,           -- 科系一
    intention2,            -- 就讀意願二
    system2,               -- 學制二
    department2,           -- 科系二
    intention3,            -- 就讀意願三
    system3,               -- 學制三
    department3,           -- 科系三
    junior_high,           -- 就讀或畢業國中
    current_grade,         -- 目前年級
    line_id,               -- LineID
    facebook,              -- Facebook
    remarks,               -- 備註
    status,                -- 狀態 (pending/contacted/enrolled)
    admin_comment,         -- 管理員備註
    created_at,            -- 建立時間
    updated_at             -- 更新時間
)
```

## 使用流程

### 學生填寫流程
1. 以學生身份登入系統
2. 點擊首頁的「就讀意願登錄」卡片
3. 填寫個人基本資料（姓名、身分別、聯絡電話等）
4. 選擇就讀意願（最多三個，包含學制和科系）
5. 填寫國中資訊和社群媒體資訊
6. 添加備註（可選）
7. 同意聲明並完成驗證碼驗證
8. 提交表單

### 老師管理流程
1. 以老師身份登入系統
2. 進入老師平台
3. 點擊「就讀意願管理」卡片
4. 查看申請列表和統計資訊
5. 使用篩選功能查找特定申請
6. 點擊「查看」按鈕查看詳細資料
7. 點擊「更新狀態」按鈕更新申請狀態

## 表單欄位說明

### 必填欄位
- **姓名**: 申請人姓名
- **身分別**: 學生或家長
- **聯絡電話1**: 主要聯絡電話

### 選填欄位
- **性別**: 男或女
- **聯絡電話2**: 次要聯絡電話
- **電子郵件**: 電子郵件信箱
- **就讀意願**: 最多三個意願，每個包含意願、學制、科系
- **國中資訊**: 就讀或畢業國中、目前年級
- **社群媒體**: LineID、Facebook
- **備註**: 額外說明或特殊需求

## 狀態說明

- **待聯絡 (pending)**: 新提交的申請，尚未聯絡
- **已聯絡 (contacted)**: 已與申請人聯絡過
- **已入學 (enrolled)**: 申請人已正式入學

## 技術特色

- **響應式設計**: 支援桌面和行動裝置
- **表單驗證**: 前端和後端雙重驗證
- **reCAPTCHA**: 防止機器人提交
- **即時統計**: 動態更新申請統計
- **篩選功能**: 多條件篩選申請
- **詳細檢視**: 模態框顯示完整資訊

## 安裝與設定

1. 確保資料庫連線正常
2. 系統會自動創建 `enrollment_applications` 資料表
3. 設定 reCAPTCHA 金鑰（目前使用測試金鑰）
4. 確保管理員權限設定正確

## 注意事項

- 系統會自動檢查並創建必要的資料表
- reCAPTCHA 目前使用測試金鑰，正式環境需要更換
- 所有API都包含適當的錯誤處理
- 表單提交後會自動重置並顯示成功訊息
- 管理員可以隨時更新申請狀態
