# 餐廳推薦功能 - 完整使用範例

## 📖 這個文件提供完整的使用範例，幫助您快速上手

---

## 🎯 完整流程範例

### 場景：推薦一間新發現的義式餐廳

---

## 第一步：發布餐廳推薦

### 1. 進入留言板
- 登入系統後，點擊「在校生留言板」
- 點擊「發布留言」按鈕

### 2. 選擇「推薦餐廳」類型
- 在「留言類型」下拉選單中選擇「**推薦餐廳**」
- 此時會顯示餐廳相關的欄位

### 3. 搜尋餐廳
**方式一：使用自動完成（推薦）**
```
在「搜尋餐廳位置」欄位輸入：冰到 MoonDay
→ Google Maps 會自動顯示建議
→ 點擊正確的餐廳
→ 系統自動填入：餐廳名稱、地址、座標、評分、價格等級
```

**方式二：手動搜尋**
```
1. 在「搜尋餐廳位置」欄位輸入：冰到 MoonDay 義式小廚房
2. 點擊「搜尋」按鈕
3. 從搜尋結果中選擇正確的餐廳
4. 點擊餐廳項目，系統自動填入信息
```

### 4. 填寫表單

**基本信息（自動填入）**
- ✅ 餐廳名稱：冰到 MoonDay 義式小廚房
- ✅ 餐廳地址：台北市內湖區民權東路六段296巷36號
- ✅ 座標：自動填入（用於地圖顯示）

**評分信息（需要選擇）**
- ⭐ 餐廳評分：選擇「5 星 - 非常推薦」
- 🏍️ 外送評分：選擇「4 星」（因為有使用過外送服務）
- 💰 價格等級：自動填入「$$ - 中等」（可手動修改）

**留言內容**
- 📝 留言標題：`推薦內湖超好吃的義式小廚房！`
- 📝 留言內容：
```
最近在學校附近發現了一間超棒的義式餐廳「冰到 MoonDay 義式小廚房」！

推薦理由：
1. 價格實惠，學生也能負擔得起（平均 $150-200）
2. 義大利麵和披薩都很道地，醬汁濃郁
3. 老闆人很親切，服務態度很好
4. 有提供外送服務，下雨天不想出門很方便

推薦菜色：
- 奶油培根義大利麵（$150）- 醬汁濃郁，培根很香
- 瑪格麗特披薩（$200）- 餅皮薄脆，起司很香
- 每日特餐（$120）- 每天都有不同的特餐，CP值很高

位置就在民權東路六段，從學校走路約 10 分鐘，非常方便！

營業時間：11:30-21:00
電話：02-2793-1234
```

### 5. 提交
- 點擊「發布留言」按鈕
- 系統會顯示「留言發布成功！」

---

## 第二步：查看餐廳推薦

### 在留言板查看

1. **返回留言板**
   - 點擊「返回留言板」或直接進入留言板頁面

2. **查看推薦餐廳分類**
   - 點擊頂部的「推薦餐廳」分類標籤
   - 您會看到所有餐廳推薦，以特殊卡片形式顯示

3. **查看餐廳信息卡片**
   ```
   ┌─────────────────────────────────────┐
   │ 🍽️ 冰到 MoonDay 義式小廚房          │
   │ 📍 台北市內湖區民權東路六段296巷36號│
   │ ⭐ 5/5  🏍️ 外送 4/5  💰 $$        │
   │ [在地圖上查看]                      │
   └─────────────────────────────────────┘
   ```

---

## 第三步：在地圖上查看餐廳

### 1. 打開地圖
- 點擊餐廳卡片中的「**在地圖上查看**」按鈕
- 地圖會在新分頁打開

### 2. 查看餐廳位置
- 地圖會自動：
  - 定位到餐廳位置（25.0685, 121.6123）
  - 顯示餐廳標記（🍽️ 橙色圓形圖標）
  - 自動打開信息窗口，顯示餐廳名稱和地址

### 3. 規劃路線
- 點擊信息窗口中的「**規劃路線**」按鈕
- 系統會：
  - 獲取您當前位置作為起點
  - 將餐廳位置設為終點
  - 顯示多條路線選項
  - 顯示詳細的轉向指示

### 4. 選擇交通方式
可以選擇：
- 🚗 開車
- 🏍️ 摩托車
- 🚶 步行
- 🚌 大眾運輸
- 🚴 自行車

---

## 第四步：評價餐廳

### 1. 進入評價頁面
- 在餐廳推薦卡片中，點擊「**查看評價與留言**」按鈕
- 進入餐廳評價頁面

### 2. 發布評價

**填寫評價表單：**

1. **選擇評分**
   - 點擊星星選擇評分（例如：點擊第 4 顆星 = 4 星評分）
   - 星星會變成黃色表示已選擇

2. **選擇外送評分（選填）**
   - 如果有使用外送服務，選擇外送評分
   - 例如：選擇「4 星」

3. **填寫評價內容**
   ```
   我也去吃過這間！真的很好吃！

   優點：
   - 義大利麵的醬汁很濃郁，不會太膩
   - 披薩的餅皮很薄很脆，起司很香
   - 價格真的很實惠，學生也能負擔
   - 老闆人很好，會關心用餐體驗

   小缺點：
   - 用餐時間人比較多，可能要等位
   - 外送時間有時候會比較久（約 30-40 分鐘）

   整體來說還是很推薦！CP值很高！👍
   ```

4. **提交評價**
   - 點擊「發布評價」按鈕
   - 系統會顯示「評價發布成功！」

### 3. 查看其他評價
- 在頁面下方可以看到所有評價
- 每個評價顯示：
  - 評價者姓名
  - 發布時間
  - 評分（星星）
  - 外送評分（如果有）
  - 評價內容

---

## 第五步：對評價留言

### 1. 在評價下方留言
- 找到您想回應的評價
- 在評價下方的輸入框中輸入留言

**範例留言 1：**
```
請問外送大概要等多久？我也想試試看外送服務！
```

**範例留言 2：**
```
我上次叫外送大概等了 35 分鐘，建議可以提前訂！
```

### 2. 提交留言
- 點擊「留言」按鈕
- 留言會立即顯示在評價下方

### 3. 查看留言
- 所有留言會顯示在對應的評價下方
- 顯示留言者姓名、時間和內容

---

## 📊 完整數據流程圖

```
1. 發布餐廳推薦
   ↓
   senior_messages 表（包含餐廳信息）
   ↓
2. 查看餐廳推薦
   ↓
   留言板顯示餐廳卡片
   ↓
3. 在地圖上查看
   ↓
   地圖標示餐廳位置
   ↓
4. 評價餐廳
   ↓
   restaurant_reviews 表
   ↓
5. 對評價留言
   ↓
   restaurant_comments 表
```

## 💡 實用技巧

### 搜尋餐廳時
- ✅ 使用完整餐廳名稱更容易找到
- ✅ 確認地址是否正確
- ✅ 如果找不到，可以手動輸入名稱和地址

### 撰寫推薦時
- ✅ 提供具體的推薦理由
- ✅ 分享推薦的菜色和價格
- ✅ 說明位置和交通方式
- ✅ 提供實用信息（營業時間、電話等）

### 撰寫評價時
- ✅ 誠實分享用餐體驗
- ✅ 說明優點和缺點
- ✅ 提供實用的建議
- ✅ 保持友善和尊重
