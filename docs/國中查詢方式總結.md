# 系統中查詢國中的方式總結

本文檔總結了系統中所有查詢國中（國民中學）的地方和實現方式。

## 一、主要查詢函數

### 1. `fetchJuniorHighSchools()` - 核心查詢函數

**位置：** `Topics-frontend/frontend/api/school_data_api.php` (第187-196行)

**SQL 查詢：**
```sql
SELECT name, city, district, type, school_code, address, phone, website, data_source 
FROM school_data 
WHERE type = '國民中學' AND is_active = 1 
ORDER BY city, district, name
```

**特點：**
- 從 `school_data` 資料表查詢
- 篩選條件：`type = '國民中學'` 且 `is_active = 1`
- 按城市、區域、學校名稱排序

---

## 二、API 端點查詢方式

### 1. 搜尋國中學校 (`action=search`)

**API 路徑：** `api/school_data_api.php?action=search&keyword={關鍵字}&city={城市}`

**實現位置：** `Topics-frontend/frontend/api/school_data_api.php` (第202-320行)

**查詢流程：**
1. 調用 `fetchJuniorHighSchools($pdo)` 獲取所有國中
2. 在 PHP 記憶體中進行模糊匹配：
   - 學校名稱模糊匹配 (`stripos($school['name'], $keyword)`)
   - 學校代碼匹配 (`stripos($school['school_code'], $keyword)`)
   - 地址模糊匹配 (`stripos($school['address'], $keyword)`)
   - 縣市區匹配 (`stripos($school['city'], $keyword)` 或 `stripos($school['district'], $keyword)`)
3. 去重處理（使用標準化後的學校名稱和城市作為唯一鍵）
4. 限制返回結果最多 20 筆

**前端調用範例：**
```javascript
fetch(`api/school_data_api.php?action=search&keyword=${encodeURIComponent(keyword)}&v=20241014-4`)
```

**使用頁面：**
- `cooperation_upload.php`
- `continued_admission.php`
- `mobile_junior.php`
- `admission_recommend.php`
- `admission.php`

---

### 2. 獲取城市列表 (`action=cities`)

**API 路徑：** `api/school_data_api.php?action=cities`

**實現位置：** `Topics-frontend/frontend/api/school_data_api.php` (第322-328行)

**查詢方式：**
```php
$schools = fetchJuniorHighSchools($pdo);
$cities = array_unique(array_column($schools, 'city'));
```

---

### 3. 按城市查詢學校 (`action=schools_by_city`)

**API 路徑：** `api/school_data_api.php?action=schools_by_city&city={城市名稱}`

**實現位置：** `Topics-frontend/frontend/api/school_data_api.php` (第330-350行)

**SQL 查詢：**
```sql
SELECT name, city, district, type, school_code 
FROM school_data 
WHERE city = ? AND type = '國民中學' AND is_active = 1 
ORDER BY district, name
```

---

### 4. 檢查學校是否存在 (`action=check_school`)

**API 路徑：** `api/school_data_api.php?action=check_school&school_name={學校名稱}`

**實現位置：** `Topics-frontend/frontend/api/school_data_api.php` (第369-391行)

**SQL 查詢：**
```sql
SELECT name, city, district, type, school_code, address, phone, website 
FROM school_data 
WHERE name LIKE ? AND is_active = 1
```

## 三、統計分析查詢

### 1. 國中選擇科系統計

**位置：** `Topics-frontend/frontend/api/enrollment_stats_api.php` (第390-496行)

**函數：** `getSchoolDepartmentStats($pdo, $department_filter)`

**查詢方式：**
從 `enrollment_intention` 表中查詢 `junior_high` 欄位，統計每個國中選擇的科系：

```sql
SELECT 
    COALESCE(junior_high, '未填寫') as school_name,
    COALESCE(intention1, '無特定') as department,
    COUNT(*) as count,
    '第一志願' as priority
FROM enrollment_intention 
WHERE junior_high IS NOT NULL AND junior_high != '' 
    AND intention1 IS NOT NULL AND intention1 != '' AND intention1 != '無特定'
GROUP BY junior_high, intention1

UNION ALL

-- 第二志願和第三志願的類似查詢...
```

**特點：**
- 查詢 `enrollment_intention` 表的 `junior_high` 欄位
- 統計三個志願的科系選擇
- 按國中分組統計

## 四、資料表結構

### 1. `school_data` 表

**用途：** 儲存所有學校資料（包括國中）

**相關欄位：**
- `name`: 學校名稱
- `city`: 城市
- `district`: 區域
- `type`: 學校類型（國中為 `'國民中學'`）
- `school_code`: 學校代碼
- `address`: 地址
- `phone`: 電話
- `website`: 網站
- `is_active`: 是否啟用（1=啟用，0=停用）

**查詢條件：**
```sql
WHERE type = '國民中學' AND is_active = 1
```

---

### 2. `enrollment_intention` 表

**用途：** 儲存就讀意願登錄資料

**相關欄位：**
- `junior_high`: 就讀或畢業國中（VARCHAR(200)）

**查詢方式：**
```sql
WHERE junior_high IS NOT NULL AND junior_high != ''
```

---

## 五、前端使用方式

### 1. 即時搜尋功能

**實現位置：** 多個前端頁面（如 `cooperation_upload.php` 第398-470行）

**JavaScript 函數：** `performSearch()`

**流程：**
1. 用戶在輸入框輸入關鍵字
2. 調用 `api/school_data_api.php?action=search`
3. 顯示搜尋結果下拉選單
4. 用戶點選後自動填入完整學校名稱（格式：`學校名稱 (城市區域)`）

**格式驗證：**
提交時驗證格式必須為：`學校名稱 (城市區域)`
```javascript
if (!preg_match('/^.+ \(.+\)$/', $junior_high)) {
    // 驗證失敗
}
```

## 六、查詢方式總結

| 查詢場景 | 查詢方式 | 資料表 | 關鍵條件 |
|---------|---------|--------|---------|
| 搜尋國中列表 | `fetchJuniorHighSchools()` | `school_data` | `type = '國民中學' AND is_active = 1` |
| 模糊搜尋學校 | PHP 記憶體匹配 | `school_data` | 先查全部，再 PHP 過濾 |
| 按城市查詢 | SQL WHERE | `school_data` | `city = ? AND type = '國民中學'` |
| 統計分析 | SQL GROUP BY | `enrollment_intention` | `junior_high IS NOT NULL` |
| 檢查學校存在 | SQL LIKE | `school_data` | `name LIKE ? AND is_active = 1` |

---

## 七、注意事項

1. **資料表名稱：** 主要使用 `school_data` 表，不是 `schools` 表
2. **學校類型：** 必須使用 `'國民中學'` 作為類型值
3. **啟用狀態：** 查詢時必須加上 `is_active = 1` 條件
4. **格式要求：** 提交的國中名稱格式必須為 `學校名稱 (城市區域)`
5. **去重處理：** 搜尋結果會進行去重，使用標準化後的學校名稱和城市作為唯一鍵
