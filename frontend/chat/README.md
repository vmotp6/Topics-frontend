這是一個支持私聊和群組聊天的系統，適用於教師和廠商之間的溝通。

### 3. Teacher表要求
聊天系統需要 `teacher` 表包含以下欄位：
- `id` - 主鍵
- `user_id` - 關聯到user表的id
- `name` - 教師姓名
- `department` - 教師科系

確保 `teacher` 表與 `user` 表正確關聯。

## 文件說明

### 主要文件
- `chat.php` - 主要的聊天界面
- `group_management.php` - 群組管理API
- `load_private_messages.php` - 載入私聊訊息
- `save_private_message.php` - 儲存私聊訊息

### 測試文件
- `test_chat_connection.php` - 測試數據庫連接和功能
- `create_chat_tables.sql` - 創建數據庫表的SQL腳本

## 功能特性

### 私聊功能
- 教師可以與同科系的其他教師聊天
- 教師可以與所有廠商聊天
- 廠商可以與所有教師聊天
- 實時訊息更新（每3秒輪詢一次）

### 群組聊天功能
- 教師可以創建群組
- 支持添加多個成員
- 群組訊息實時同步
- 群組成員管理

### 用戶界面
- 現代化的聊天界面
- 響應式設計
- 訊息快取機制
- 自動滾動到最新訊息

## 使用步驟

### 1. 測試連接
首先訪問 `test_chat_connection.php` 來檢查：
- 數據庫連接是否正常
- 必要的表是否存在
- 用戶數據是否正確

或者訪問 `test_teacher_table.php` 專門測試teacher表。

### 2. 創建數據庫表
如果缺少表，執行 `create_chat_tables.sql` 中的SQL語句。

### 3. 開始使用
訪問 `chat.php` 開始使用聊天功能。

## 故障排除

### 常見問題
1. **數據庫連接失敗**
   - 檢查IP地址 100.79.58.120 是否正確
   - 確認MySQL服務正在運行
   - 檢查防火牆設置

2. **表不存在**
   - 執行 `create_chat_tables.sql`
   - 確認數據庫權限

3. **用戶數據缺失**
   - 確保 `user` 表中有用戶數據
   - 確保 `teacher` 表中有教師數據

4. **群組功能不工作**
   - 檢查 `group_management.php` 是否存在
   - 確認群組相關表已創建

### 調試建議
- 使用瀏覽器開發者工具查看JavaScript錯誤
- 檢查PHP錯誤日誌
- 使用 `test_chat_connection.php` 進行診斷

## 安全注意事項
- 確保數據庫連接使用適當的權限
- 考慮添加用戶身份驗證
- 定期備份聊天數據
- 監控系統性能

## 技術規格
- PHP 7.4+
- MySQL 5.7+
- 現代瀏覽器支持
- 響應式設計
