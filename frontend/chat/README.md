# 學生聊天系統設置說明

## 概述
這是一個支持私聊和群組聊天的系統，適用於學生和教師之間的溝通。系統已從廠商對老師改為學生對老師的聊天模式。

### 3. 必要的表結構
聊天系統需要以下表：

#### Teacher表
- `id` - 主鍵
- `user_id` - 關聯到user表的id
- `name` - 教師姓名
- `department` - 教師科系

#### Student表
- `id` - 主鍵
- `user_id` - 關聯到user表的id
- `name` - 學生姓名
- `student_id` - 學號
- `department` - 學生科系
- `grade` - 年級
- `class_name` - 班級名稱
- `email` - 電子郵件
- `phone` - 電話號碼

確保 `teacher` 和 `student` 表與 `user` 表正確關聯。

## 功能特性

### 私聊功能
- 教師可以與同科系的其他教師聊天
- 教師可以與所有學生聊天
- 學生可以與所有教師聊天
- 實時訊息更新（每3秒輪詢一次）
- 教師可以搜尋學生（按姓名、學號、科系、年級、班級）

### 群組聊天功能
- 教師可以創建群組
- 支持添加多個成員
- 群組訊息實時同步
- 群組成員管理

### 用戶界面
- 現代化的聊天界面
- 響應式設計
- 訊息快取機制
- 自動滾動到最新訊息

## 使用步驟

### 1. 設置資料庫
首先執行 `setup_student_chat.sql` 來創建必要的表和測試資料：
- 創建學生表
- 插入測試學生資料
- 確保聊天相關表存在

### 2. 測試連接
訪問 `test_student_chat.php` 來檢查：
- 數據庫連接是否正常
- 必要的表是否存在
- 學生和教師數據是否正確
- 聯絡人查詢是否正常

### 3. 開始使用
訪問 `chat.php` 開始使用聊天功能。

## 故障排除

### 常見問題
1. **數據庫連接失敗**
   - 檢查IP地址 100.79.58.120 是否正確
   - 確認MySQL服務正在運行
   - 檢查防火牆設置

2. **表不存在**
   - 執行 `create_chat_tables.sql`
   - 確認數據庫權限

3. **用戶數據缺失**
   - 確保 `user` 表中有用戶數據
   - 確保 `teacher` 表中有教師數據

4. **群組功能不工作**
   - 檢查 `group_management.php` 是否存在
   - 確認群組相關表已創建

### 調試建議
- 使用瀏覽器開發者工具查看JavaScript錯誤
- 檢查PHP錯誤日誌
- 使用 `test_chat_connection.php` 進行診斷

## 安全注意事項
- 確保數據庫連接使用適當的權限
- 考慮添加用戶身份驗證
- 定期備份聊天數據
- 監控系統性能
