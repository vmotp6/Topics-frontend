🔧 資料庫表格清理工具

⚠️ 重要提醒： 在執行任何資料庫操作前，請務必備份您的資料庫！刪除資料表是不可逆的操作。
📋 使用說明： 此工具可以幫助您分析資料庫中的表格，識別哪些表格是未使用的，並安全地刪除它們。

📝 建議操作步驟：

  1. 第一步： 點擊「分析資料庫表格」來查看所有表格的詳細分析
  2. 第二步： 檢查分析結果，確認哪些表格可以安全刪除
  3. 第三步： 如果需要刪除表格，點擊「刪除未使用的表格」
  4. 第四步： 謹慎選擇要刪除的表格並確認操作

📋 3. 核心系統表格說明

以下表格是聊天系統的核心，絕對不能刪除：

  • user - 用戶基本資料表
  • teacher02 - 教師詳細資料表
  • private_chat_history - 私聊訊息記錄表
  • group_chats - 群聊資料表
  • group_chat_members - 群聊成員表
  • group_chat_messages - 群聊訊息記錄表
  • ai_chat_history - AI聊天記錄表

🔧 4. 系統表格說明

以下表格是MySQL系統表格，不能刪除：

  • mysql - MySQL系統資料表
  • performance_schema - 效能監控資料表
  • phpmyadmin - phpMyAdmin管理資料表
  • test - 測試資料表
